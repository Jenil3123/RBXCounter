# RBXCounter Companion App

This is a premium Roblox-inspired companion application built with React Native, Expo, and strict TypeScript.

## Project Architecture
The project follows **Clean Architecture** combined with a feature-based structure. 
State management is handled entirely by **Zustand**, and data fetching via **TanStack Query**.

## Core Commands
- `npm run start` - Start Expo development server
- `npm run android` - Run on Android emulator (must be running)
- `npm run typecheck` - Run strict TypeScript compilation check
- `npm run lint` - Run ESLint checks
- `npm run format` - Format codebase with Prettier
